# 策略与默认值（policy）

**职责**：默认值、跳过/回退、跨题补充规则、术语、画幅算法、输出目录、总出图上限（触发与 N）、输出命名的**单一事实源**。  
**不写**：题面 Options、G1/G2 收束步骤、prompt 模板正文、风格/氛围/布局/忠实度表行原文。  
跨文件只留指针；细则以 SKILL 权责表为准。

**术语**（定义见本处）：内部「标题区 / 布局」；「横幅」= 底/顶/侧铭牌（溶字有标题区、无横幅）。

布局取值与语义 → [title-layouts.md](title-layouts.md)。模板与溶字旁饰 → prompts；文件名布局后缀 → 下方「输出命名」。

## 配置与回退

### 默认配置（Q1=a；跳过同 a）

主表不含标题文字 / 文字风格；该项按下方「布局分支」补全（a 路径布局恒为无 → 不适用）。不做多风格。

| 内部项 | 取值 |
|--------|------|
| 标题区 / 布局 | 无 / 无 |
| 风格模式 / 画面风格列表 | 单风格 / `[0]` |
| 忠实度 | 形似 |
| 氛围开关 / 氛围 | 关 / 无 |
| 装饰边框 | 不要边框 |
| 画幅比例 | 按源图映射（复述中告知结果） |
| 输出目录 | 源图所在目录 |

### 布局分支（标题文字 / 文字风格）

先定布局，再补全；**勿**在布局∈{底,顶,侧,溶字} 时沿用「不适用」。

| 条件 | 标题文字 | 文字风格 |
|------|----------|----------|
| 布局 = 无 | 不适用（不生成题字） | 不适用 |
| 布局 ∈ {底, 顶, 侧, 溶字} 且该项未说明 | 文件名（同 Q5 跳过） | `0`（同 Q6 跳过） |
| 布局 ∈ {底, 顶, 侧, 溶字} 且该项已说明 | 按各题记录 | 按各题记录 |

### 按所述配置（Q1=c）

1. 已说明项按各题记录规则解析（见 question-cards 各题，非仅 Q1）
2. 未说明项先套用上方主表
3. 再按「布局分支」补全标题文字 / 文字风格（有标题区且未说明 → 文件名 + `0`；无标题区 → 不适用）
4. **氛围**：已有合法取值（判定见 Q9）→ `开` + 该值；仅有「要氛围」等意图、无合法取值 → `开`，按 [question-cards.md](question-cards.md) Q9 追问选型（**不问 Q8**；跳过/无效同 Q9）；未提及 → 主表（关 / 无）

无可解析偏好 → 回退 a。生成前必读见 SKILL「读什么」。

### 多风格共用

布局、标题、文字风格（非 0）、忠实度、氛围、边框、比例、目录全风格共用；仅 `{IMAGE_STYLE}`、输出名风格短名、文字风格为 0 时的 `{FONT_STYLE}` 随项变。

- **风格列表**：解析与回退见 question-cards Q2
- **文字风格**：解析与回退见 question-cards Q6；`{FONT_STYLE}` 见 prompts
- **忠实度**：取值见 [fidelity-levels.md](fidelity-levels.md)；句末按布局追加见 prompts `{FIDELITY}`

### 氛围

全任务统一。表列见 [mood-styles.md](mood-styles.md)；选用/装配见 prompts `{MOOD}`。

- 合法取值判定与匹配 → question-cards Q9
- Q1=c 三段（有值 / 仅意图追问 / 未提及）→ 上方「按所述配置」
- 自定义路径：Q8 开后问 Q9；跳过/二次无效 → 取消（关 / 无），见 Q9
- **禁止** `开` 且 `氛围=无`（问答结算后、生成前；Q8/Q9 或 c 仅意图待答期间为中间态，Q9 跳过/无效后改为关）

## 生成前落定

### 画幅比例

支持：`1:1` / `4:3` / `3:4` / `16:9` / `9:16`。

落定（总流程「画幅」步）：
- 已有比例取值（Q4 记录，或 a/c 主表 / 已说明）→ 直接用；固定比例则全批统一
- 取值为「按源图映射」→ 逐图映射并复述
- 取值为「按源图映射」且读不到源图 → 追问用户（不占幕内题位），勿默用 `1:1`
- 禁止因本步再次询问 Q4

映射：`r=宽/高`；`|r−1|≤0.1` → `1:1`；`r>1` → `4:3` 或 `16:9` 取近者；`r<1` → `3:4` 或 `9:16` 取近者。

侧条+横图：复述提示「竖图更合适」，不强制改比例。

### 标题文字

- 未说明 → 上方「布局分支」
- 文件名 → 源名去扩展名作 `{TITLE}`（按**门控后**源图逐张）
- **AI 拟定** →（出图门控若有）→ 对门控后源图拟定并一次确认 → 通过：复述后生成 / 否决：用户手输标题（不重拟、不退回 Q5）→ 复述后生成
- 自定义标题 → 全批共用

### 总出图上限

`T=M×K`（M=门控前源数，K=风格数）；**N=9**。

- `T≤9` → 放行；`T>9` → G1/G2（question-cards「总出图上限门控」）→ 须 `M'×K'≤9`
- 无单独源数/风格数上限；Q2 不截断风格个数
- 含 Q1=a（K=1 且 M>9）

收束步骤（G1/G2 选项与选后计算）→ [question-cards.md](question-cards.md)「总出图上限门控」；**此处不复述公式**。

## 输出

### 输出目录

- 默认 → 批量各回源图目录；自定义 → 本批进该路径
- 生成结果按「输出命名」落到上述目录；若工具写在他处则**移动**到位（不留临时副本），再处理同名
- **永不覆盖源文件**
- 同名**输出**已存在 → 本批问一次：是 → 覆盖冲突项；否 / 跳过 / 未明确 → **不覆盖、不中止**，冲突项改名写入（非冲突项仍用原定名）
- 改名：扩展名前加 `-2`、`-3`…（递增），例 `photo-绘本水粉.png` → `photo-绘本水粉-2.png`

### 输出命名

取源文件名去扩展名后稀疏拼接（默认档不写入文件名），段序固定。

```text
{源文件名去扩展名}-{风格短名}[-{忠实度}][-{氛围}][-有边框]{布局后缀}
```

| 段 | 取值 | 写入条件 |
|----|------|----------|
| 风格短名 | 表内→[image-styles.md](image-styles.md)「文件名短名」；自定义风格提炼 2–4 字 | 始终 |
| 忠实度 | [fidelity-levels.md](fidelity-levels.md)「忠实度」列原文 | ≠ `形似` |
| 氛围 | 表内→[mood-styles.md](mood-styles.md)「氛围」列；自定义氛围提炼 2–4 字 | 氛围 ≠ 无 |
| 有边框 | 固定词 `有边框` | 要边框 |
| 布局后缀 | 下表；布局取值见 [title-layouts.md](title-layouts.md) | 始终（无为 `.png`） |

自定义风格/氛围短名避开非法字符，复述时告知。

| 布局 | 布局后缀 | 示例 |
|------|----------|------|
| 无 | `.png` | `photo-绘本水粉.png` |
| 底 | `-底横幅.png` | `photo-绘本水粉-底横幅.png` |
| 顶 | `-顶横幅.png` | `photo-绘本水粉-顶横幅.png` |
| 侧 | `-侧条.png` | `photo-绘本水粉-侧条.png` |
| 溶字 | `-溶字.png` | `photo-绘本水粉-溶字.png` |

例：`photo-绘本水粉-紧贴-雨夜-有边框-底横幅.png`；`photo-绘本水粉-黄昏-溶字.png`（形似默认不写）。
