# 默认配置与取值规则

默认值与跨题补充规则的**单一事实源**。提问卡「记录」见 [question-cards.md](question-cards.md)；取值表见各 references。SKILL / 其它文件只留指针或红线摘要，细则以本文件与 prompts 为准。

**术语**（定义见本处）：内部「标题区 / 布局」；「横幅」= 底/顶/侧铭牌（溶字有标题区、无横幅）。

## 默认配置（Q1=a；跳过同 a）

主表不含标题文字 / 文字风格；该项按下方「布局分支」补全（a 路径布局恒为无 → 不适用）。不做多风格。

| 内部项 | 取值 |
|--------|------|
| 标题区 / 布局 | 无 / 无 |
| 风格模式 / 画面风格列表 | 单风格 / `[0]` |
| 忠实度 | 形似 |
| 氛围开关 / 氛围 | 关 / 无 |
| 装饰边框 | 不要边框 |
| 画幅比例 | 按源图映射（复述中告知结果） |
| 输出目录 | 源图所在目录 |

### 布局分支（标题文字 / 文字风格）

先定布局，再补全；**勿**在布局∈{底,顶,侧,溶字} 时沿用「不适用」。

| 条件 | 标题文字 | 文字风格 |
|------|----------|----------|
| 布局 = 无 | 不适用（不生成题字） | 不适用 |
| 布局 ∈ {底, 顶, 侧, 溶字} 且该项未说明 | 文件名（同 Q5 跳过） | `0`（同 Q6 跳过） |
| 布局 ∈ {底, 顶, 侧, 溶字} 且该项已说明 | 按各题记录 | 按各题记录 |

## 按所述配置（Q1=c）

1. 已说明项按各题记录规则解析（见 question-cards Q1）
2. 未说明项先套用上方主表
3. 再按「布局分支」补全标题文字 / 文字风格（有标题区且未说明 → 文件名 + `0`；无标题区 → 不适用）
4. **氛围**：仅合法取值（表内编号 / 严格表名 / 可落地自定义一句）→ `开` + 该值；仅有「要氛围」等意图 → **关 / 无**（不问 Q9）

无可解析偏好 → 回退 a。生成前必读见 SKILL「读什么」。

## 取值与补充

| 事项 | 规则 |
|------|------|
| 多风格共用 | 布局、标题、文字风格（非 0）、忠实度、氛围、边框、比例、目录全风格共用；仅 `{IMAGE_STYLE}`、输出名风格短名、文字风格为 0 时的 `{FONT_STYLE}` 随项变 |
| 风格列表 | 解析与回退见 question-cards Q2；跨风格共用见上方「多风格共用」 |
| 文字风格 | 解析与回退见 question-cards Q6；多风格时 0/非 0 见上方「多风格共用」；`{FONT_STYLE}` 见 prompts |
| 忠实度 | 取值见 [fidelity-levels.md](fidelity-levels.md)。与画面风格正交；布局相关句末追加（含底/顶/侧只约束插画区、溶字+紧贴）见 prompts `{FIDELITY}` |
| 氛围 | 与画面风格正交；全任务统一。表列见 [mood-modifiers.md](mood-modifiers.md)；选用/装配见 prompts `{MOOD}`。合法取值=表内编号 / 严格表名（匹配见 Q9）/ 可落地自定义一句；无合法取值 ⇒ `关/无`（c 路径见上；自定义路径 Q9 跳过/二次无效 → 取消，见 question-cards）。禁止 `开` 且 `氛围=无` |
| 布局 | 取值/`{BANNER_LAYOUT}` 见 [banner-layouts.md](banner-layouts.md)；文件名后缀见 SKILL「场景与命名」。溶字 ≠ 布局无（溶字仅标题字；布局无绝对无字） |
| 画幅比例 | 支持 `1:1` / `4:3` / `3:4` / `16:9` / `9:16`。映射：`r=宽/高`；`|r−1|≤0.1` → `1:1`；`r>1` → `4:3` 或 `16:9` 取近者；`r<1` → `3:4` 或 `9:16` 取近者。读不到源图 → 问用户（不占幕内题位），勿默用 `1:1`。按源图映射时批量逐图映射并复述；Q4 指定固定比例则全批统一。侧条+横图：复述提示「竖图更合适」，不强制改比例 |
| 输出目录 | 默认 → 批量各回源图目录；自定义路径 → 本批全部进该路径；**永不覆盖源文件**。同名**输出**已存在 → 本批问一次是否覆盖那些冲突输出：是 → 覆盖冲突项；否 / 跳过 / 未明确要覆盖 → **不覆盖、不中止**，对冲突项改名写入（非冲突项仍用原定名）。改名：在扩展名前加 `-2`、`-3`…（该候选仍存在则递增），例 `photo-绘本水粉.png` → `photo-绘本水粉-2.png` |
| 标题文字 | 未说明时见上方「布局分支」。文件名 → 源名去扩展名作 `{TITLE}`（按**门控后**源图逐张）；**AI 拟定** → G1/G2 后、完整复述前：对门控后源图拟定并一次确认 → 再复述与生成确认；否决则请用户手输标题（不重拟、不退回 Q5），再复述确认；自定义标题 → 全批共用 |
| 多风格 × 多源 | 仅 1 源可开多风格（1×K，K=2～3）。多源且多风格 → G1/G2（question-cards）。**禁止** M×K；纯批量（单风格多源）不设总出图上限 |
