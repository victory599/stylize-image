# 提问卡与记录规则

**职责**：题面、Options、记录字段、门控时点与分批的单一事实源。  
**不写**：默认主表、画幅映射、输出命名/目录算法、prompt 模板、表行原文。  
**上限**：触发与 N → [policy.md](policy.md)「总出图上限」；收束问答与选后算法 → **仅**本文 G1/G2（他处勿另写/摘要公式）。

## 提问方式

照搬下方 Question/Options，勿改写成段落。  
优先结构式交互（如 `AskUserQuestion`）；禁止纯文本罗列选项让用户手输。  
无该工具时：按幕分条，提示按序简答（例：幕1 `0,2,5；a；默认`），勿要求一次答完全部幕。

## 分批与批量

- **自定义**：每轮 ≤3 题（分批事实源；细则见各幕——幕3 有专条；G1 须单独一轮）
- **批量**：整批共用一套配置，配置问答不按图重复；比例映射、输出名按图；标题：文件名/AI 按图，自定义标题全批共用

## 选项标记

- 字母：仅 Q1 / Q3 / Q5 / Q7 / G1
- 表内编号：Q2 / Q6 / Q9
- 其余白话
- 字母与档名同义（如 Q3 `b` /「底部横幅」→ 底）；对用户白话，术语 → [policy.md](policy.md)

## 必问与跳过

- Q1=a（或跳过→a）：跳过 Q2–Q11
- Q1=c：跳过 Q2–Q11（Q9 例外 → [policy.md](policy.md)「按所述配置」氛围）
- 其余：每题须问到并记录；跳过/未确定 → 该题默认项

## Q1 配置路径

先问 Q1 → a/c：跳过规则见上方「必问与跳过」；b → 幕1。a/c 超限 → 下方门控（c：风格解析后即门控，Q9 若需要则门控后再问）。时点细则 → 下方「总出图上限门控」。

```
Question: 怎么配置这次转换？
Options:
- a 用默认配置（无标题、单风格-绘本水粉、形似；无氛围/边框；比例与输出跟源图）
- b 自定义（分步选择）
- c 按所述配置（本轮已说的偏好；未说明项按默认补全；大体不问 Q2–Q11；氛围未点名时可能追问）
```

**记录**：`配置路径 = [默认配置 / 自定义 / 按所述配置]`
- **跳过** → 默认配置（不做多风格）
- **a**：复述列出 policy 主表要点（勿只说「默认」）
- **c**：解析与回退 → [policy.md](policy.md)「按所述配置」；风格解析后超限 → 下方门控；需追问氛围则门控后问 Q9；复述注明补全项

## 📌 幕1 · 核心（Q2–Q4）

流转：Q2 →（超限？ → 下方门控）→ Q3 → Q4。分批：Q2 超限后，G1/G2 各占单独一轮；门控完再进 `Q3` 或 `Q3+Q4`（每轮 ≤3）。

### Q2 画面风格

问前读 [image-styles.md](image-styles.md) 并展示全表。上限规则 → [policy.md](policy.md)「总出图上限」（题干须带上限提示，见 Question）。

```
Question: 画面风格怎么选？（完整风格表见上方；总出图=源数×风格数，上限见 policy）
Options:
- 0 复古绘本水粉（默认 · 单风格）
- 1 日系动画电影感写实光影
- 2 胶片静帧插画
- 用户自由输入（表内编号；多风格只认编号，如 0,2,5 或 0、2、5 或 0，2，5；或直接描述想要的单风格）
```

**记录**：
- **字段**：`风格模式 = [单风格 / 多风格]`；`画面风格列表 = [{风格}, …]`
- **选项**：`0`/`1`/`2` → 单风格，列表长 1
- **越界数字**：表内 `#` 外的纯数字 → `0` 并告知（多风格列表内同理，替换后再去重）
- **分隔**：`,` / `、` / `，`（两侧空白可忽略）；**不**认纯空格分隔为多风格列表
- **多风格**：拆分后各项均为纯数字，去重后 ≥2 → 多风格（**不**截断个数）；去重后仅 1 个 → 单风格并告知；无有效项 → 单风格 `[0]`
- **无效多选**（名称多选、编号与名称混排等，如 `水彩,浮世绘`、`0,极简主义`）：告知仅支持表内编号列表（或单段自定义描述）→ 再问一次 Q2；第二次仍无效或跳过 → 单风格 `[0]`
- **单风格**：单个表内编号；单段非纯数字描述（含 `0 5 12` 空格串，整段当描述）→ 列表长 1，按 [prompts.md](prompts.md) 精化并提炼短名
- **跳过 / 空** → `[0]`（单风格）
- **复述**：多风格须列全项（含短名）
- **结算**：超限？ → 是：下方门控 → Q3；否 → Q3

### Q3 标题区布局

```
Question: 标题区怎么放？
Options:
- a 不要（默认。无标题区、画面无字）
- b 底部横幅（约占短边 1/3）
- c 顶部横幅（约占短边 1/3）
- d 左侧题条（约占宽度 1/4～1/3）
- e 溶进画面（无铭牌底板，字叠在留白处；仍有标题字）
```

**记录**：
- **字段**：`标题区 = [a → 无；b/c/d/e → 有]`；`布局 = [a → 无；b → 底；c → 顶；d → 侧；e → 溶字]`（取值见 [title-layouts.md](title-layouts.md)；术语见 policy）。仅 a–e（及等价白话）
- **跳过** → 无
- **非选项**（含右侧题条）：告知不支持，按无（**勿**收成「有意图→底」）
- **口语 / Q1=c**（未走本题选项时）：
  - **有标题意图**＝明确出现（或明显同义）：要标题 / 加标题 / 要字 / 题字 / 横幅 / 铭牌 / 溶字 / 侧条 / banner / title
  - 「好看一点」「风格化一下」等 → 不算（c → 未说明 → 主表布局=无）
  - 已指明底/顶/侧/溶字（或本卡等价白话）→ 按所指
  - 有意图未指哪一种 → **底**

## 📌 幕3 · 调味与输出（Q7–Q11）

顺序：Q7 → Q8 →（开：Q9 →）Q10 → Q11。关则跳过 Q9。

**分批**（受文首「每轮 ≤3」约束）：
- 先 `Q7`，或同批 `Q7+Q8`；**Q8 结算前**不得问其后各题
- Q8=开 → 问前展示氛围表；本批 `Q9` 或 `Q9+Q10+Q11`
- Q8=关 → 本批 `Q10+Q11`（不问 Q9）
- Q9 重问/取消不影响已答的 Q10/Q11

### Q7 忠实度

```
Question: 和源图要贴多紧？
Options:
- a 形似（默认）：认得是同一题材，允许适度概括
- b 紧贴：主体位置与构图尽量对齐，只换画法
- c 再演绎：只保留主题与情绪，构图可大胆改
```

**记录**：`忠实度 = [形似 / 紧贴 / 再演绎]`（见 [fidelity-levels.md](fidelity-levels.md)）
- **跳过** → 形似

### Q8 情绪 / 季节氛围（开关）

```
Question: 要不要给画面加一层情绪/季节氛围？（不改画风，只调光色与天气/环境感）
Options:
- 不要（默认，依据源图）
- 要
```

**记录**：
- **字段**：`氛围开关 = [关 / 开]`
- **判定**：跳过或明确否定 → 关；明确肯定 → 开；无法判断 → 关
- **关** → `氛围 = 无`，不问 Q9
- **Q1=c**：不经本卡

### ▶ Q9 氛围选型

**何时问**：自定义且 Q8=开；Q1=a 不问；Q1=c：仅 policy「按所述配置」氛围之「仅意图」时（门控之后、画幅之前）。  
问前读 [mood-styles.md](mood-styles.md)，只展示 **# / 氛围**。自定义分批 → 上方幕3。

```
Question: 选哪个氛围？（完整氛围表见上方）
Options:
- 1 雨夜
- 2 黄昏
- 3 初雪
- 用户自由输入（表内编号/名称，或一句话描述）
```

**记录**：
- **字段**：`氛围 = [编号 / 名称 / 自定义描述]`
- **名称**：与表「氛围」列去空白后**严格全等**（「雨夜」≠「雨」）；禁止模糊/子串/近义
- **编号**：须在表内；越界 → 无效
- **非编号且非严格表名**：像一句话 → 自定义；无法判断 → 无效
- **跳过**（首次或第二次）→ **取消氛围**（关、`氛围 = 无`）；即使此前已开（Q8=开 或 Q1=c 仅意图）
- **无效**（首次）→ 告知原因并再问一次 Q9；第二次仍无效或跳过 → 取消氛围

## 🚪 总出图上限门控（G1 / G2）

本题卡为提问 / 记录 / 收束步骤事实源（触发与 N 见 [policy.md](policy.md)「总出图上限」）。

**源序**：门控前将本轮源图固定为有序枚举，G2 选项按此序展示；凡「取前 / 前 N」均指该序（含 G1=c 的「源序前 9」）。

```text
时点：a：套用默认后；b：Q2 后、Q3 前；c：风格解析后（先于 c 的 Q9）
  → 未超限 → 跳过
  → G1（单独一轮；勿与 Q2/Q3 同批）
  → 需减源 → G2（G1 结算后再问，勿与 G1 同屏）
  → 其后问答（含 c 的 Q9）/ 标题 / 生成 只对门控后集合
  → 复述须写明门控后保留的源与风格
```

题干代入当前 `M`、`K`、`T`（N 见 policy）。

### G1 收束方式

```
Question: 将生成 M×K=T 张（上限 9）。怎么收束？
Options:
- a 重选风格（可单可多；总出图超限则再裁源）
- b 保留风格、减少源图
- c 自动压到不超过 9 张（默认）
```

**记录**：`出图门控 = [a / b / c]`
- 选项对用户只展示上表短文案；收束步骤见下方（勿把公式念给用户）
- **a**：G1 轮只收 a/b/c；选 a 后下一轮再按 Q2 规则问风格，解析为新列表与 `K'`；跳过/空/无效 → 留在 G1（不适用 Q2 默认 `[0]`）

```text
跳过 → c
  → a → 得 K' 后：
        → K'>9？ → 告知风格最多 9 → 留在 G1（可再选 a/b/c）
        → M×K'≤9？ → 是：源全留，采用新列表
        → 否：采用新列表 → G2（S_max=floor(9/K')）
  → b → K>9？ → 告知不可用 → 留在 G1（可再选 a/b/c）
        → 否：风格不变 → G2（S_max=floor(9/K)）
  → c → M≤9？ → 源全留，风格=列表前 K'=floor(9/M) 个
        → 否：源=源序前 9，风格=列表第一项
```

### G2 减少源图（G1=a 且 M×K'>9，或 G1=b）

```
Question: 保留哪些源图？（最多 S_max 张，其余本次跳过）
Options:
- （按源序生成：每项一个文件名，必要时加序号如 1. foo.jpg）
- 取前 S_max 张（默认）
- 用户自由输入（文件名或列表序号，1～S_max 张）
```

**记录**：`门控后源图 = [命中的 1～S_max 张]`

```text
S_max：G1=a → floor(9/K')；G1=b → floor(9/K)
  → 跳过 / 无效 / 空 / 无法对应 → 取前 S_max（源序）
  → 超选 → 按平台返回顺序取前 S_max 并告知
  → 有效 1～S_max 张 → 采用；未入选源本次跳过
```
