# 提问卡与记录规则

照搬下方 Question/Options，勿改写成段落。须用平台结构式交互工具（如 `AskUserQuestion`）；禁止纯文本罗列选项让用户手输。无交互工具时按幕分条列出，提示按序简答（例：幕1 答 `0,2,5；a；默认`），勿要求一次答完全部幕。

自定义路径：**每轮 ≤3 题**（分批事实源）。批量：全局配置只请示一轮；比例映射、标题、输出名随图推导。

**字母**：仅 Q1 / Q3 / Q5 / Q7 / G1 用字母；Q2 / Q6 / Q9 用表内编号；其余白话。字母与档名同义（如 Q3 答 `b` 或「底部横幅」→ 底）。对用户白话；内部术语见 [defaults.md](defaults.md)。

除 Q1 选 a/c（或跳过→a）整段跳过后续各幕外，每题须问到并记录；跳过/未确定 → 该题默认项。

## Q1 配置路径

先问 Q1 → a/c 则跳过后续各幕；b 自定义进幕1。

```
Question: 怎么配置这次转换？
Options:
- a 用默认配置（无标题区 · 单风格 0 绘本水粉 · 形似 · 无氛围 · 无边框 · 比例按源图映射 · 输出到源图目录）
- b 自定义（分步选择）
- c 按所述配置（本轮已说的偏好；其余同默认；不问 Q2–Q11）
```

**记录**：`配置路径 = [默认配置 / 自定义 / 按所述配置]`。
- 跳过 → 默认配置（不做多风格）
- **c**：按各题规则解析已说明项；其余见 [defaults.md](defaults.md)「按所述配置」。无可解析偏好 → 回退 a。多风格×多源 → G1/G2。复述注明补全项。

## 📌 幕1 · 核心（Q2–Q4）

顺序：Q2 → Q3 → Q4（可同批；≤3 见文首）。

### Q2 画面风格

问前读 [image-styles.md](image-styles.md) 并展示全表。

```
Question: 画面风格怎么选？（完整风格表见上方）
Options:
- 0 复古绘本水粉（默认 · 单风格）
- 1 日系赛璐珞动画风
- 2 厚涂油画
- 用户自由输入（表内编号；多风格只认编号，如 0,2,5 或 0、2、5 或 0，2，5；或直接描述想要的单风格）
```

**记录**：
- `风格模式 = [单风格 / 多风格]`；`画面风格列表 = [{风格}, …]`
- 选 `0`/`1`/`2` → 单风格，列表长 1
- 表内 `#` 范围外的纯数字 → `0` 并告知（多风格列表内同理，替换后再去重）
- 自由输入分隔符：`,` / `、` / `，`（两侧空白可忽略）；**不**认纯空格分隔为多风格列表
  - **多风格**：拆分后每一项均为纯数字，去重后 ≥2 → 多风格；超过 3 个只取前 3 并告知；去重后仅 1 个 → 单风格并告知；无有效项 → `[0]`
  - **无效多选**（名称多选、编号与名称混排等，如 `水彩,木刻`、`0,赛博朋克`）：告知仅支持表内编号列表（或单段自定义描述），**再问一次** Q2；第二次仍无效或跳过 → 单风格 `[0]`
  - **单风格**：单个表内编号；单个越界数字 → `[0]`；单段非纯数字描述（含 `0 5 12` 这种空格串，整段当描述）→ 列表长 1，按 [prompts.md](prompts.md) 精化并提炼短名
- 跳过或空输入 → 单风格 `[0]`
- 复述时多风格须列全项（含短名）

### Q3 标题区布局

```
Question: 标题区怎么放？
Options:
- a 不要（默认。无标题区、画面无字）
- b 底部横幅（约占短边 1/3）
- c 顶部横幅（约占短边 1/3）
- d 左侧题条（约占宽度 1/4～1/3）
- e 溶进画面（无铭牌底板，字叠在留白处；仍有标题字）
```

**记录**：`标题区 = [a → 无；b/c/d/e → 有]`；`布局 = [a → 无；b → 底；c → 顶；d → 侧；e → 溶字]`（取值见 [banner-layouts.md](banner-layouts.md)；术语见 defaults）。仅 a–e（及等价白话）。跳过 → 无。
**有标题意图未指布局 → 底**。「有标题意图」仅当用户明确出现下列之一（或明显同义）：要标题 / 加标题 / 要字 / 题字 / 横幅 / 铭牌 / 溶字 / 侧条 / banner / title。仅说「好看一点」「风格化一下」等 → 不算（c 路径按未说明 → 主表布局=无）。已指明底/顶/侧/溶字（或本卡等价白话）→ 按所指；只表意图未指哪一种 → 底。
非选项（含右侧题条）→ 告知不支持，按无（勿收成「有意图→底」）。

### Q4 画幅比例

```
Question: 画幅比例？
Options:
- 按源图映射到最近支持比例（默认，结果会告知你）
- 1:1
- 4:3
- 用户自由输入（3:4 / 16:9 / 9:16）
```

**记录**：`画幅比例 = [支持比例之一，或按源图映射]`；跳过 → 按源图映射。非法输入（如 `2:1`）→ 告知并回退映射（批量仍逐图映射）。算法见 [defaults.md](defaults.md)。

## ▶ 幕2 · 标题（Q5–Q6）

仅当布局 ∈ {底, 顶, 侧, 溶字} 时问 Q5 → Q6；否则整幕跳过。

### Q5 标题文字

```
Question: 标题文字怎么定？
Options:
- a 用图片文件名（默认）
- b 让 AI 根据画面拟一个（生成前会给你确认文案）
- 用户自由输入（自定义标题）
```

**记录**：`标题文字 = [a → 文件名；b → AI 拟定；自由输入 → 用户原文]`；跳过 → 文件名。自定义标题：单图用原文；**批量全批共用**，复述写明。**Q5=b（AI 拟定）**：时序与否决→手输见 [defaults.md](defaults.md)「标题文字」。

### Q6 文字风格

问前读 [font-styles.md](font-styles.md) 并展示全表。

```
Question: 标题文字风格选哪个？（完整风格表见上方）
Options:
- 0 与画面风格一致（默认）
- 1 绘本手绘感标题字
- 2 新艺术风格描金曲线字
- 用户自由输入（表内编号，或直接描述想要的风格）
```

**记录**：`文字风格 = [编号 / 0 / 自定义描述]`。纯数字越界 → `0` 并告知；非数字 → 自定义；跳过 → 0。多风格时 0/非 0 见 [defaults.md](defaults.md)「多风格共用」；`{FONT_STYLE}` 见 [prompts.md](prompts.md)。

## 📌 幕3 · 调味与输出（Q7–Q11）

顺序：Q7 → Q8 →（开：Q9 →）Q10 → Q11。关则跳过 Q9。≤3 见文首。

**分批**：先 `Q7` 或 `Q7+Q8`；Q8 结算前不得问其后各题。其后：开 → `Q9`（问前展示氛围表，可与 Q10+Q11 同批）；关 → `Q10+Q11`。Q9 重问/取消不影响已答的 Q10/Q11。

### Q7 忠实度

```
Question: 和源图要贴多紧？
Options:
- a 形似（默认）：认得是同一题材，允许适度概括
- b 紧贴：主体位置与构图尽量对齐，只换画法
- c 再演绎：只保留主题与情绪，构图可大胆改
```

**记录**：`忠实度 = [形似 / 紧贴 / 再演绎]`（见 [fidelity-levels.md](fidelity-levels.md)）；跳过 → 形似。

### Q8 情绪 / 季节氛围（开关）

```
Question: 要不要给画面加一层情绪/季节氛围？（不改画风，只调光色与天气/环境感）
Options:
- 不要（默认，依据源图）
- 要
```

**记录**：`氛围开关 = [关 / 开]`。跳过或明确否定 → 关；明确肯定 → 开；无法判断 → 关。关 → `氛围 = 无`，不问 Q9。Q1=c 不经本卡（氛围规则见 defaults）。

### ▶ Q9 氛围选型（仅自定义路径且 Q8=开）

Q8 已开之后读 [mood-modifiers.md](mood-modifiers.md)，只展示 **# / 氛围**；分批见上方幕3。Q1=a/c 不问本卡。

```
Question: 选哪个氛围？（完整氛围表见上方）
Options:
- 1 雨夜
- 2 黄昏
- 3 初雪
- 用户自由输入（表内编号/名称，或一句话描述）
```

**记录**：`氛围 = [编号 / 名称 / 自定义描述]`。名称须与表「氛围」列去空白后**严格全等**（「雨夜」≠「雨」）；禁止模糊/子串/近义。编号须在表内；越界无效。非编号且非严格表名 → 像一句话则自定义；无法判断 → 无效。

- **跳过**（首次或第二次）→ **取消氛围**（关氛围、`氛围 = 无`）；跳过 Q9 即取消氛围，即使 Q8 曾开
- **无效**（首次）→ 告知原因并**再问一次** Q9；第二次仍无效或跳过 → 取消氛围

### Q10 边框

```
Question: 要不要装饰边框？
Options:
- 不要（默认）
- 要
```

**记录**：`装饰边框 = [要边框 / 不要边框]`；跳过 → 不要边框。

### Q11 输出目录

```
Question: 输出到哪个目录？
Options:
- 源图所在目录（默认）
- 用户自由输入（自定义路径）
```

**记录**：`输出目录 = [路径]`；跳过 → 源图所在目录。默认/自定义批量规则见 [defaults.md](defaults.md)。

## 🚪 多风格 × 多源门控（G1 / G2）

仅多风格且源图 >1 时，在生成前复述之前：先 G1；G1=b 再 G2。

### G1 处理方式

```
Question: 多风格不能和多张源图一起用，怎么处理？
Options:
- a 取消多风格：全批共用单一风格（默认用列表第一项，复述时写明短名）
- b 只对其中一张源图做多风格，其余源图本次跳过
```

**记录**：`多源门控 = [a / b]`；跳过 → a（列表收束为第一项，单风格，全批源图保留）。

### G2 指定源图（仅 G1=b）

```
Question: 对哪一张源图做多风格？（其余本次跳过）
Options:
- （由 agent 按当前源图列表生成：每项一个文件名，必要时加序号如 1. foo.jpg）
- 用户自由输入（文件名或列表序号）
```

**记录**：`多风格源图 = [命中的一张]`。须唯一对应（文件名或序号）。跳过/无效/不唯一 → 告知并回退 G1=a。b 且指定成功：仅该源进生成，其余跳过（不自动改跑单风格，除非用户另行要求）。
